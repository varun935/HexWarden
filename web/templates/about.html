The Problem

Malware hidden in power sector hardware firmware sits below the OS, invisible to antivirus, and can trigger blackouts on command. Industroyer did exactly this to Ukraine's power grid in 2016.

How HexWarden Works

EA

Entropy Analysis

Detects encrypted/compressed payloads using CFAR guard-band local contrast.

GD

Golden-Image Diff

Content-defined chunking finds exactly what changed between clean and suspect firmware.

YE

YARA Engine

Matches known ICS malware signatures (Industroyer, Triton, BlackEnergy, HAVEX).

FF

Filesystem Forensics

Catches backdoor accounts, suspicious cron jobs, pre-installed SSH keys.

SA

String Analysis

Finds hardcoded C2 IPs, shell commands, credentials in binary firmware.

NM

Network Monitor

Detects C2 beacon timing, DNS tunneling, suspicious outbound connections.
